This post is showcase of a project I have made on python using the pygame library. The project is called 'Logic Goat' and allows users to create logic circuits and test them. 
<div style="text-align: center;">
    <img src="![alt]({{ site.url }}{{ site.baseurl }}/assets/logicGoat/1.png" alt="ls command output" style="width: 500px;"/>
</div>
How to use:
<ul>
    <li>Gates can be added from the side bar or using the numbers 1-9</li>
    <li>Gates can be deleted by clicking on them then pressing backspace</li>
    <li>Gates connected through dragging the mouse between connection nodes</li>
    <li>Connections removed through right clicking connection node</li>
    <li>File saved using the button on sidebar</li>
</ul>
