## Toddler's bottle
### <u>fd
So the description for this challenge is:
```
Mommy! what is a file descriptor in Linux?
```
A quick google search tell us "a file descriptor (FD) is a non-negative integer that serves as a unique identifier or "handle" for an open file or other input/output (I/O) resource". 0 is stdin, 1 is stdout and 2 is sterr. Once we ssh into the challenge we find a file with the following c code:
```
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
char buf[32];
int main(int argc, char* argv[], char* envp[]){
	if(argc<2){
		printf("pass argv[1] a number\n");
		return 0;
	}
	int fd = atoi( argv[1] ) - 0x1234;
	int len = 0;
	len = read(fd, buf, 32);
	if(!strcmp("LETMEWIN\n", buf)){
		printf("good job :)\n");
		setregid(getegid(), getegid());
		system("/bin/cat flag");
		exit(0);
	}
	printf("learn about Linux file IO\n");
	return 0;

}
```
It seems like the code takes in an arugement as a string, converts it to an integers and substracts by 4660. Then it uses that result as the file descriptor as it reads from the buffer. This means we should run the program with the argument 4660. Doing so causes the program to read from stdin into buf. If we then provide the input LETMEWIN\n, the string comparison succeeds, and the program prints the success message and outputs the flag.
```
fd@ubuntu:~$ ./fd 4660
LETMEWIN
good job :)
Mama! Now_I_understand_what_file_descriptors_are!
```

### <u> Collision
Description we get for this challenge:
```
Daddy told me about cool MD5 hash collision today.
I wanna do something like that too!
```
An MD5 hash collision is when two differents get hashed with the MD5 and produce the same output.


For this challenge we have the file col.c which contains:
```
#include <stdio.h>
#include <string.h>
unsigned long hashcode = 0x21DD09EC;
unsigned long check_password(const char* p){
	int* ip = (int*)p;
	int i;
	int res=0;
	for(i=0; i<5; i++){
		res += ip[i];
	}
	return res;
}

int main(int argc, char* argv[]){
	if(argc<2){
		printf("usage : %s [passcode]\n", argv[0]);
		return 0;
	}
	if(strlen(argv[1]) != 20){
		printf("passcode length should be 20 bytes\n");
		return 0;
	}

	if(hashcode == check_password( argv[1] )){
		setregid(getegid(), getegid());
		system("/bin/cat flag");
		return 0;
	}
	else
		printf("wrong passcode.\n");
	return 0;
}
```
After reading the code we can see you pass in an argument as the password, then the check_password function converts each 4 chars to an int then sums them. The result is compared against the hashcode variable which is equal to the decimal value 568,134,124. So if we split our 20 input bytes into the values [113626825,113626825,113626825,113626825,113626824] then we can equal to that value. So our input should be:
```
col@ubuntu:~$ ./col `python2 -c "print '\xc9\xce\xc5\x06'*4 + '\xc8\xce\xc5\x06'"`
Two_hash_collision_Nicely
```
