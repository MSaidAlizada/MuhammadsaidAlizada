This level will require knowledge of robots.txt which is a file on a website that gives instructions to bots that crawl websites on the pages they can and cannot access. 

Now in the level instead of the flag being in the comment we get this hint:

### Level 8:
```
Username: natas8
Password: xcoXLmzMkoIP9D7hlgPlh9XD7OgLAe5Q
URL:      http://natas8.natas.labs.overthewire.org
```
Again we have to input a secret and we are also given the source code. But this time we are shown the encoded secret. By looking at the function to encode we can see they encode it in base 64 then reverse it and then finally change it from binary to hex. So to decode the secret we will do the reverse to the encoded secret: "3d3d516343746d4d6d6c315669563362"  
First we change it from hex to binary with this line of php:
```
echo hex2bin("3d3d516343746d4d6d6c315669563362");
```
And we get: "==QcCtmMml1ViV3b"  
Now we reverse this:
```
echo strrev("==QcCtmMml1ViV3b");
```
Getting: "b3ViV1lmMmtCcQ"  
Now we base 64 decode this:
```
echo base64_decode("b3ViV1lmMmtCcQ==");
```
Finally we have the secret "oubWYf2kBq" which when we submit we get:  
Access granted. The password for natas9 is ZE1ck82lmdGIoErlhQgWND6j2Wzz6b6t
